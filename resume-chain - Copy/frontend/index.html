Getting Started ℹ️

  1. Install MetaMask: You need a crypto wallet to interact with this DApp. Download MetaMask.
  2. Create or Access Wallet: Open MetaMask and either create a new wallet or log in to your existing wallet. Keep your seed phrase safe.
  3. Connect to the Network: For local development, connect MetaMask to Hardhat Local Network (127.0.0.1:8545). For live deployment, connect to the appropriate network.
  4. Understand the Portals:
    • 🎓 University Portal: Register your university, add students, approve skill tests, post results.
    • 👨‍🎓 Student Portal: Register using verified university details, upload your resume CID, request skill tests, view results & notifications.
    • 🏢 Employer Portal: Register your company, search for students by skills, view resumes, send job notifications.
  5. Usage Tips: Ensure MetaMask is connected and the correct account is selected before performing any action. All actions are permanent on the blockchain.
